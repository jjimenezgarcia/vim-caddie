# Swapping ends of a selection

Once a visual selection is started, `o` jumps the cursor to the
*other* end of it — the end you didn't start from:

- `v` to a spot, then `o` — the cursor jumps to where you started, and
  now extending the selection moves that end instead

Useful when a selection turned out to need adjusting from the
beginning instead of where it currently ends.
