# Incrementing and decrementing numbers

`Ctrl-a` and `Ctrl-x` find the number nearest the cursor (at or after
it, on the current line) and add or subtract from it:

- `Ctrl-a` — increment the number by one
- `Ctrl-x` — decrement the number by one
- `5 Ctrl-a` — increment it by five

No need to select the digits or retype them — Vim finds the number and
does the arithmetic.
