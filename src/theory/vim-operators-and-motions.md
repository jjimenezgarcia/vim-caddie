# Operators + motions

Combine any operator with any motion to get a command — you're not
memorizing separate commands for "delete a word" and "change a word,"
just combining pieces you already know:

- `d` + `w` → `dw` — delete to the start of the next word
- `c` + `e` → `ce` — change to the end of this word
- `y` + `b` → `yb` — yank back to the start of this word
