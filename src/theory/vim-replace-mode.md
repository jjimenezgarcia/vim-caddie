# Replace mode

`R` enters replace mode: a sustained version of `r` that keeps
overtyping character-for-character until you press `Esc`, instead of
replacing just one and returning to normal mode.

- `R` — start overtyping from the cursor
- `Esc` — stop and return to normal mode

Unlike insert mode, every character you type consumes one character
already there, rather than pushing the rest of the line forward.
