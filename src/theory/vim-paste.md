# Pasting

Whatever was last deleted or yanked lives in a register, ready to be
dropped back into the buffer:

- `p` — paste after the cursor (or below the current line, for a
  line-wise yank or delete)
- `P` — paste before the cursor (or above the current line)

A `dd` followed by `p` a couple lines down is how you move a line, not
just copy it.
