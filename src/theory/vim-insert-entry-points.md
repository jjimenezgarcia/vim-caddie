# Ways into insert mode

There's more than one way to start typing, and each one places the
cursor somewhere different first:

- `i` — insert before the cursor
- `a` — insert after the cursor
- `I` — insert at the start of the line
- `A` — insert at the end of the line
- `o` — open a new line below and insert there
- `O` — open a new line above and insert there

All six end the same way: press `Esc` to drop back to normal mode.
