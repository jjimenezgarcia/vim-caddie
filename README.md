# ⛳ Vim Caddie

> **Gamified Vim learning: solve puzzles, save keystrokes, master the terminal.**

Vim Caddie is a gamified web application designed to teach Vim text editor mechanics through logic puzzles. Inspired by the concept of "Vim Golf," the goal isn't just to solve the puzzle, but to achieve the perfect keystroke par.

## 🌟 Features

* **Vim Golf Mechanics:** Solve text-editing puzzles using the absolute minimum number of keystrokes.
* **Interactive Grid:** A visual, beginner-friendly interface that simulates a terminal without the intimidation factor.
* **Real-time Feedback:** Tracks your current mode (Normal/Insert) and counts your strokes as you type.
* **Progressive Difficulty:** Start with basic movements (`h`, `j`, `k`, `l`) and scale up to complex text surgery.
